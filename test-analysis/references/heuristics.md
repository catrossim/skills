# 隐含需求挖掘启发式

需求文档通常只写成功路径和主要规则；线上缺陷集中在需求没写的区域。本章 9 个维度是挖掘隐含功能点的固定检查表。使用方式：**对每个显式功能点，逐维度套用提问模板**；凡是"需求没写、但行为有明确定义"的，产出为功能点并标 `[推导]`；凡是"需求没写、行为也无从定义"的，进待确认项。

优先级建议：推导条目默认 P1/P2；涉及钱、数据丢失、权限的推导条目升级 P0/P1。

## 1. 错误与异常处理

对每个操作问：**"当 X 失败时，系统应该……？需求是否规定了？"**

- 依赖服务失败 / 超时 / 部分失败：下游接口挂了、第三方超时、批量操作中断
- 网络异常：请求中断、弱网重试、断点续传
- 失败后的状态：是否回滚、已执行的部分怎么办、用户如何重试

典型遗漏：只定义了"调用成功"的行为，失败时无任何定义。

## 2. 输入与校验

对每个输入域问：**"这个字段能接收什么？不能接收什么？非法值怎么办？"**

- 必填性：空值、未填写直接提交
- 格式：类型、格式（手机号/邮箱/日期）、特殊字符、emoji、超长文本、前后空格
- 校验位置：前端拦截（不发请求）还是服务端兜底，两层是否一致
- 注入类输入：脚本、SQL、路径穿越字符（与 §6 安全维度交叉）

## 3. 状态与生命周期

对每个有状态的实体问：**"它有哪几个状态？哪些迁移是合法的？非法迁移会发生什么？"**

- 画出全部状态与迁移路径（含回退：取消、退款、撤销、恢复）
- 非法迁移的拦截：已删除的资源再操作、终态再变更
- 状态与展示：各状态下入口按钮的可用性、列表筛选的可见性

典型遗漏：需求只写了"下单→支付"正向路径，取消/退款/超时关单的迁移无定义。

## 4. 权限与访问控制

对每个资源和操作问：**"谁能做？谁不能做？不能做的人直接发请求会怎样？"**

- 认证：未登录访问需登录功能
- 授权：无权限角色访问、普通用户调管理员接口（越权）
- 资源归属：用户 A 用 ID 直接访问用户 B 的资源（水平越权 / IDOR）
- 权限变化的生效时机：降权/禁用后已有会话是否立即失效

## 5. 数据一致性与幂等

对每个写操作问：**"重复提交会怎样？并发操作同一份数据会怎样？"**

- 幂等：表单双击、接口重试、网络超时后的重复请求
- 并发修改：两人同时编辑/同时抢库存/同时用同一张券
- 事务边界：跨表/跨服务操作部分失败后的一致性
- 删除影响：删除被引用的数据、软删后关联数据的表现

## 6. 会话与安全

问：**"会话失效时机？敏感信息会出现在哪？"**

- 会话过期后的行为：跳登录页、保留当前页待回跳、丢失的表单数据
- 多端会话：互踢还是共存、修改密码后旧 token 是否失效
- 敏感信息：日志不打明文密码/token、错误提示不泄露内部信息（如"账号不存在"vs"密码错误"的口径）
- 频控：防刷限制（验证码、限流）——仅需求规定或高风险时收

## 7. 空态与边界

问：**"第一次用/没数据的时候，页面长什么样？"**

- 空态：空列表、无搜索结果、首次进入的引导
- 数据量边界：0 条、1 条、大数据量分页、末页删除
- 极值：数量上限（0/1/最大值）、金额上下限、时间边界（当天 00:00、跨天）

注意：这里只收"行为定义"（如"空列表显示引导图与新建入口"）；具体取哪些边界值去测，留给下游用例层。

## 8. 时序与竞态

问：**"两个动作几乎同时发生，结果是什么？"**

- 过期/截止时刻的竞态：到期瞬间提交、过期瞬间下单
- 乱序到达：回调先于结果页、消息先于状态更新
- 重复触发：轮询与手动刷新叠加、快速切换页面

## 9. 明确的非功能项

仅在两种情况下收录：需求明确规定了（如"接口 P95 < 1s"），或高风险模块的常规底线（如支付接口防重放）。来源标注规则不变：需求规定的标 `需求§`，行业惯例底线标 `[推导]`。

## 挖掘产出的去向

| 挖掘结果 | 去向 | 来源标注 |
|----------|------|----------|
| 需求没写、行为有明确定义（行业惯例/一致性要求） | §2 功能点清单 | `[推导]` |
| 需求没写、行为无定义且影响主流程 | §3 待确认项 | —（写明暂采用假设） |
| 需求没写、可测可不测的边缘场景 | 不收录，避免清单膨胀 | — |

挖掘完成后自查一遍：每个维度至少过了一次问句；推导条目数量显著多于显式条目（如 >2:1）时，警惕过度推导——优先保留与钱、数据、权限相关的，其余降级或舍弃。
